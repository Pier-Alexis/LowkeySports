# Expo HAS CHANGED

This project runs on **Expo SDK 54** (React Native 0.81.5, React 19.1.0). This is important: SDK 54 differs from newer SDKs in several ways (native tabs need `Icon`/`Label` top-level imports from `expo-router/unstable-native-tabs`, and `@react-navigation/native` supplies `ThemeProvider`/`DarkTheme`).

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.
